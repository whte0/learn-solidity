## 📂 Repository Structure

This repository is organized by difficulty level and project type for easy navigation.

- **`/01-Beginner`** — Understanding basic syntax, data types, and initial logic flow.
- **`/02-Intermediate`** — Advanced concepts like complex data structures, inheritance, and gas efficiency.
- **`/Mini-Projects`** — Implementation of theories into fully functional smart contracts.
- **`/Notes`** — Theoretical notes and blockchain concepts.
